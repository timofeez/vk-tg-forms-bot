# Пересылка из беседы VK в Telegram

Бот раз в минуту проверяет беседу VK и пересылает в Telegram сообщение, если:

- его написал преподаватель (`TEACHER_IDS`);
- **и** в нём есть ссылка на форму (Google, Яндекс, Microsoft) или слова вроде «форма», «запись», «сдача».

Ссылки на формы ищутся и в пересланных сообщениях и ответах, а ключевые слова только в тексте самого сообщения.

В Telegram: `/start` подписаться, `/stop` отписаться. Подписаться может любой, кто найдёт бота.

## Как понять, что бот работает

Первый подписавшийся становится владельцем. Ему:

- каждый день после 9:00 по Москве приходит отчёт «🟢 Бот работает» со статистикой за сутки;
- если бот 10 минут не может прочитать беседу (например, VK отозвал токен), приходит «⚠️», а после восстановления «✅».

**Нет отчёта до полудня = бот не работает.** Если запуск в GitHub Actions упадёт, GitHub ещё и пришлёт письмо.

## Хостинг: GitHub Actions

Workflow `.github/workflows/bot.yml` запускается каждые 10 минут; каждый запуск работает около 55 минут, а следующие ждут в очереди, поэтому перерывы получаются короткими.
Состояние (позиция в беседе, подписчики) хранится в кэше Actions между запусками.
Раз в неделю workflow делает коммит `.keepalive`, иначе GitHub отключил бы расписание через 60 дней.

Секреты репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `VK_TOKEN` | токен вашего аккаунта VK |
| `TG_BOT_TOKEN` | токен бота от @BotFather |
| `VK_PEER_ID` | номер беседы: `python bot.py --chats` |
| `TEACHER_IDS` | ID преподавателя: `python bot.py --check 200` при пустом `TEACHER_IDS` |

Задать секрет из терминала (значение вводится скрыто):

```bash
gh secret set VK_TOKEN
```

## Токен VK

Беседу бот читает от вашего аккаунта, потому что бота-сообщество в чужую беседу может добавить только её админ.
Откройте в браузере, войдя в VK:

```
https://oauth.vk.com/authorize?client_id=2685278&scope=messages,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&revoke=1
```

Подтвердите доступ и скопируйте из адресной строки значение `access_token` (до `&`).
`client_id` принадлежит приложению Kate Mobile: обычным новым приложениям VK не даёт доступ к сообщениям.

**Токен даёт полный бессрочный доступ к вашим сообщениям.** Храните его только в секретах GitHub.
Отозвать: настройки VK → «Приложения» → удалить Kate Mobile.

## Локальный запуск

`pip install requests`, создайте `.env` с теми же переменными (`KEY=значение` по строкам) и выполните `python bot.py`.
Одновременно может работать только одна копия бота: остановите Actions перед локальным запуском.
